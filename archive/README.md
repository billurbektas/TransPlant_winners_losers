# Inactive scientific history

This tree is reserved for checksum-recorded historical source and output after
canonical target-level equivalence has passed. Nothing is moved here merely to
make the active tree look cleaner. Archived R files are never sourced by
`_targets.R`.

Archive moves require a manifest row with original path, destination, category,
SHA-256, producer, dependencies, reason, and date. Deletions are a separate,
explicit approval gate.
